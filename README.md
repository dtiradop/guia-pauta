# Guías de Pauta Digital

Guías de implementación para Meta Ads, Google Ads y TikTok Ads.

- `index.html` — portada para escoger la plataforma
- `meta-ads.html` — Meta Ads por objetivo (incluye Interacción)
- `google-ads.html` — Google Ads por tipo de campaña
- `tiktok-ads.html` — TikTok Ads por objetivo

Publicado con GitHub Pages (Settings → Pages → Deploy from branch → main / root).
